# T for Conspiracy — Agent Factory

AI-powered multi-agent workflow that turns conspiracy theories into satirical merchandise concepts.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- OpenClaw on VPS
- WhatsApp channel
- Tailscale-secured access
- OpenAI GPT-5.5

## First goal

A visual dashboard that shows:

- Agent activity
- Trending topics
- Generated slogans
- T-shirt concepts
- Image prompts
- Human approval status

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

## Next integration idea

Start with mock data. Later connect this dashboard to exported OpenClaw session logs or a small API endpoint.
