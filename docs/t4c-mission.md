# T for Conspiracy

## Mission

Turn conspiracy theories into wearable satire.

## Audience

People who enjoy internet culture, memes, conspiracy lore,
absurd humor and niche online communities.

## Tone

- Clever
- Dry
- Deadpan
- Playful
- Never hateful
- Never extremist
- Never propaganda

## Goal

Generate t-shirt concepts people would genuinely wear.

## Workflow

Research
→ Slogan
→ Design Prompt
→ Human Approval
→ Store

## Output

Every concept should contain:

- Topic
- Slogan
- Description
- Design Prompt
- Score
- Status

## Success

A stranger would wear the shirt because it is funny,
not because they necessarily believe the conspiracy.
